# 바슬즐 탐험대 설치·업데이트 안내 (선생님용)

## 설치하기

1. 판매 페이지에서 받은 `tonghap-module_<버전>_x64-setup.exe`를 실행합니다.
2. **「Windows의 PC 보호」 파란 창이 뜨면**: 「추가 정보」를 누른 뒤 「실행」을 누릅니다.
   - 이 창은 프로그램에 아직 코드 서명(마이크로소프트가 확인한 개발자 표시)이 없어서 뜹니다. 바이러스가 있다는 뜻은 아닙니다.
3. 관리자 비밀번호 없이 설치됩니다(내 사용자 계정에만 설치).
4. 학교 보안 프로그램이 설치나 실행을 막으면, 학교 정보 담당 선생님께 이 프로그램 실행 허용을 요청해 주세요. 막힌 화면의 문구를 알려 주시면 함께 확인하겠습니다.

## 처음 실행한 뒤

1. **「기기 점검」 탭**에서 이 PC 사양을 확인합니다.
2. 필요한 AI 모델을 내려받습니다(학교 인터넷이 막혀 있으면 집에서 받은 파일을 「파일 선택」으로 가져올 수 있습니다).
   - 음성 자막 모델: 190MB(느린 PC는 60MB 모델)
   - 평어 초안 모델: 2.5GB
3. 「관찰 기록」 탭에서 학급을 만들고 학생 명단을 붙여 넣습니다.

## 데이터는 어디에 있나요

- 모든 기록(명단, 관찰 기록, 사진, 음성, 단원, 평어)은 **이 PC의 내 사용자 폴더 안**에만 저장됩니다. 인터넷으로 보내지 않습니다.
  - 위치: `C:\Users\<사용자 이름>\AppData\Local\io.github.oswprogram10-tech.tonghap\`
- 앱이 인터넷을 쓰는 경우는 「기기 점검」에서 AI 모델을 내려받을 때뿐입니다.

## 백업하기 (꼭 해 주세요)

- 「백업」 탭에서 암호를 정해 백업 파일(`.tonghap`)을 만들고, **USB 등 이 PC가 아닌 곳**에 보관합니다.
- 암호를 잊으면 누구도 복원할 수 없습니다.
- 7일 넘게 백업하지 않으면 관찰 기록 화면에 알림이 뜹니다.

## 업데이트하기

1. **먼저 백업 파일을 만듭니다**(만일을 위해).
2. 판매 페이지에서 새 버전 설치 파일을 받아 실행합니다. 이미 설치된 앱 위에 덮어 설치됩니다.
3. 기록과 내려받은 AI 모델은 그대로 남습니다. 새 버전을 처음 열면 데이터가 새 버전에 맞게 자동으로 바뀝니다(바꾸다 실패하면 바뀌기 전 상태로 남습니다).
4. 앱 아래쪽에 표시된 버전 번호로 업데이트되었는지 확인합니다.

## 지우기

- 윈도우 「설정 → 앱」에서 「바슬즐 탐험대」를 제거합니다.
- 제거 창의 「앱 데이터 삭제」를 **체크하지 않으면** 기록이 PC에 남습니다. 체크하면 기록도 지워지니, 그 전에 백업 파일을 만들어 두세요.
