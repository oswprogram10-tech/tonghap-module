# 개발 계획

2022 개정 초등 통합교과 1~2학년군 수업 지원 앱(가칭 **바슬즐 탐험대**)의 개발 계획입니다.
원본 명세서는 Gemini로 생성한 「2022 개정 초등 통합교과 교육과정 심층 분석 및 에듀테크 기반 통합교과 앱 개발 명세서」입니다.

## 확정된 조건

| 항목 | 결정 |
|---|---|
| 개발 인원 | 1인 |
| 배포 | 윈도우 설치 파일(exe) 다운로드. 판매는 별도 플랫폼 |
| 주 사용 기기 | 교사용 윈도우 PC (+ PC에 연결된 전자칠판) |
| AI | 기기 안에서 동작하는 로컬 모델. 필요한 부분만 미세조정 |
| 데이터 | 서버 없음. 교사 PC에만 저장, 백업은 암호화 파일 |

## 제품 정의

- 주 사용자는 **교사**입니다. 첫 버전에는 학생 계정과 학생 기기가 없습니다.
- 핵심 가치는 두 가지입니다.
  1. 오프라인 탐구·실천·놀이 활동을 1분 안에 기록 → 학생별 포트폴리오가 자동으로 쌓임
  2. 쌓인 기록을 근거로 학기 말 서술형 평가(생기부) 초안 작성 부담을 줄임
- 판매 문구: "아이 기록이 선생님 PC 밖으로 나가지 않습니다."

## 기술 구성

| 영역 | 선택 |
|---|---|
| 앱 틀 | Tauri 2 (React + TypeScript 화면, Rust 백엔드) |
| 설치 파일 | NSIS, 사용자별 설치(관리자 권한 불필요) |
| 언어 모델 | llama.cpp (GGUF, Vulkan/CUDA/CPU 자동 선택), sidecar 실행 파일 |
| 음성 인식 | whisper.cpp, sidecar 실행 파일 |
| 임베딩 | llama.cpp 임베딩 모드 (multilingual-e5-small 급) |
| 저장소 | %APPDATA% 아래 SQLite + 미디어 폴더, 윈도우 DPAPI로 암호화 키 보관 |
| 전자칠판 | 교사 PC에서 '칠판 모드' 창을 따로 띄움 |
| 교육과정 데이터 | `data/curriculum/` (CASE 개념을 단순화한 JSON + 스키마) |

## 로컬 AI 계획

| 기능 | 방식 | 학습 |
|---|---|---|
| 안내 음성 | 개발할 때 미리 음성 파일로 만들어 앱에 포함 | 없음 |
| 질문 묶기·활동 추천 | 임베딩 검색 + 규칙 | 없음 |
| 아동 음성 → 자막 | Whisper small/base | 기본 모델 오류율(WER) 측정 후 필요하면 미세조정 |
| 생기부 평어 초안 | 한국어가 되는 1.5~4B 소형 모델 + LoRA | 필요. 합성 데이터 1~3천 쌍(200~300쌍 직접 검수) |

평어 생성의 안전장치:
- 문장마다 근거 기록을 연결합니다.
- 생기부 기재 금지 표현은 규칙 필터로 걸러냅니다.
- 교사가 수정해야 확정됩니다.
- 기기 성능이 부족하면 템플릿 방식으로 대체합니다.

평어는 NEIS에 직접 입력하지 않습니다. 클립보드 복사나 텍스트 파일로 내보냅니다.

모델 라이선스는 상업 배포 가능 여부를 반드시 확인합니다(예: EXAONE은 비상업 라이선스). AI Hub 데이터도 상업적 이용 조건을 확인합니다.

## 배포 체크리스트

- [ ] 코드서명 인증서(서명되지 않은 exe는 SmartScreen 경고, 학교 보안 프로그램 차단 가능)
- [ ] 관리자 권한 없이 설치되는지 실제 학교 PC에서 확인
- [ ] 모델 파일(약 2.5GB)은 앱 안에서 이어받기 다운로드 + 오프라인 모델 팩 제공
- [ ] 판매 플랫폼의 파일 용량 제한 확인
- [ ] 서명된 자동 업데이트 + 수동 업데이트 파일
- [ ] 오프라인에서 검증되는 라이선스 파일
- [ ] 개인정보 처리방침(만 14세 미만 아동 정보를 교사 PC에서만 처리)

## 확인이 필요한 사실

명세서는 AI가 생성한 문서이므로 다음은 공식 자료로 확인해야 합니다.

- 성취기준 원문 48개 (국가교육과정정보센터 NCIC 고시문)
- 주제책 소주제와 차시 흐름 (교사용 지도서)
- 2028년 '건강한 생활' 신설 여부와 시기
- 영역별 핵심 아이디어 문구
