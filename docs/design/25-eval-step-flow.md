# 설계 25: 평어 화면을 단계형으로 (시안 C)

사용자가 고른 시안: 「평어 화면 시안」 캔버스의 **시안 C · 한 문장씩 확인하는 단계형**(https://claude.ai/artifact/GQLoKN126DQCLvWQPL5c1W#artboard-StepFlow). 근거 확인(설계 24, 2026 기재요령의 「AI 생성 문장을 그대로 입력 금지」)을 가장 분명하게 지키는 흐름이다. 지금 화면은 근거마다 「기록 보기」, 문장마다 단추 4~5개가 세로로 쌓여 학생 한 명이 모니터 2~3장 길이다.

**바꾸는 것은 화면(`src/evaluation/`)뿐**이다. Rust 명령·DB·검사 규칙은 그대로 쓴다(필요하면 읽기 전용 보조 명령만 추가). 기존 기능은 하나도 빠지지 않아야 한다.

## 1. 평어 목록 화면 (탭을 열면 처음 보이는 화면)

- 위쪽 한 줄: 제목 「평어」, 구분 단추 **[교과 · 성취수준 및 특기사항 | 통합본 | 행동특성 및 종합의견]**, 교과 구분 단추(교과일 때만, 교과 색 점), 기간 단추(「2학기 · 2026.8.1~2027.2.28 ▾」 — 누르면 학기 선택과 날짜 입력), 생성 방식 구분 단추 [템플릿 | 언어 모델](언어 모델이 없으면 템플릿만, 지금처럼 안내).
- 오른쪽: 주요 실행 하나 「학급 초안 한꺼번에 만들기」(지금 있는 기능), 그리고 「⋯」 메뉴: 학급 확정본 내보내기(통합본/교과별/행발 — 지금 형식 그대로), 문체·금지 표현 설정, 목표 글자 수.
- 본문: 학생 표(번호, 이름, 상태, 확인 진행). 위에 큰 숫자 「확정 n · 초안 n · 없음 n」. 행을 누르면 그 학생의 단계 화면으로 간다. 상태 표시는 글자+색(색만으로 구분하지 않음).
- 「초안입니다…」 안내는 한 줄로 줄여 위쪽에 둔다.

## 2. 학생 단계 화면

머리줄: 「← 평어 목록」, 「곽새론 · 슬기로운 생활 · 2학기」, 학생 고르기(「학생 1/10 ▾」), 「다음 학생 →」(다음 미확정 학생으로).

단계 표시(4칸, 현재 단계 강조, 지난 단계는 ✓와 요약): **① 근거 고르기 → ② 초안 만들기 → ③ 문장 확인 → ④ 확정 · 복사**. 지난 단계를 눌러 돌아갈 수 있다. 확정된 학생을 열면 ④에서 시작(「확정 풀기」로 다시 고칠 수 있음 — 지금 기능).

1. **근거 고르기**: 근거 목록(체크하면 초안에 씀 — 지금과 같음). 근거 한 줄 = 날짜·종류·내용 요약, 누르면 그 자리에서 펼쳐짐(지금의 「기록 보기」 단추를 없앤다). 근거 수 부족 안내 그대로. 「다음: 초안 만들기」.
2. **초안 만들기**: 생성 방식 선택과 「초안 만들기」(언어 모델은 진행·취소 지금처럼). 이미 초안이 있으면 「이 초안으로 확인하기」와 「다시 만들기」(덮어쓰기 확인). 행발은 학기 나누기·목표 글자 수가 여기.
3. **문장 확인**: 한 번에 한 문장.
   - 「문장 k / n」, 만든 방식(템플릿·언어 모델), 질문 「이 문장이 아이의 실제 모습과 맞나요?」, 큰 글상자(고치면 고친 글이 쓰임).
   - 옆에 **이 문장의 근거** 카드들. 근거가 약하면 이유 문구(아래 규칙). 「+ 다른 기록을 근거로 붙이기」(지금의 근거 붙이기 기능).
   - 단추: **「맞아요, 확인했어요」**(= 근거 확인 체크 + 다음 문장으로), 「이 문장 빼기」(= 문장 지우기, 되돌리기 가능하도록 바로 아래 「되돌리기」 한 번), 「← 이전 문장」. 마지막 문장 뒤에 「+ 문장 추가」.
   - 문장의 검사 경고(금지 표현, 다른 학생 이름, 명사형, 변화 가능성 등)는 그 문장 카드 안에 바로 보인다.
   - 아래에 **전체 글 미리 보기**: 문단 전체, 지금 문장은 노란 표시, 확인한 문장은 연한 초록, 글자 수·NEIS 바이트·확인 k/n.
   - 키보드: 글상자 밖에서 `Enter` = 확인, `←`/`→` = 이전/다음 문장. 버튼 64px 이상.
4. **확정 · 복사**: 전체 글(고칠 수 있음 — 고치면 그 문장은 확인된 상태 유지, 지금 규칙), 검사 결과 요약, 글자 수·바이트, 「확정」(남은 확인이 있으면 「3번 문장 확인 필요」처럼 단추에 표시하고 누르면 그 문장으로 이동), 언어 모델 글을 하나도 안 고쳤으면 지금의 확인 창, 확정 후 「복사」·「다음 학생 →」. 교과는 「이 교과만 복사(참고용)」와 「세 교과 모두 확정되면 통합본으로」 안내.

**약한 근거 이유 규칙(화면에서 계산)**: 그 문장의 근거가 (a) 차시·습관뿐이고 이 학생 관찰이 없으면 「차시 기록만 있고 이 학생의 관찰 기록은 없습니다. 그 모습을 보셨다면 확인하고, 아니면 문장을 빼거나 고쳐 주세요.」 (b) 근거가 없으면 「근거가 없는 문장입니다. 근거를 붙이거나 빼 주세요.」 (c) 「지도가 필요한 모습」 근거면 「단점 근거입니다. 변화 가능성이 함께 쓰였는지 확인해 주세요.」

## 3. 통합본·행발

- **통합본**(구분 단추 「통합본」): 학생 표는 세 교과 상태(바·슬·즐 ✓) + 통합본 상태. 학생 화면 단계: ① 세 교과 확인(미확정 교과는 그 교과 단계 화면으로 가는 단추) → ② 합치기·다듬기(지금 기능, 「바뀜」 안내) → ③ 전체 확인(통합본은 체크 하나, 설계 24) → ④ 확정·복사.
- **행발**: 교과와 같은 4단계. 근거 목록에 「지도가 필요한 모습」 표시.

## 4. 구현 메모

- 지금의 `StudentDraft.tsx`, `CombinedPanel.tsx`, `BehaviorPanel.tsx`의 상태·API 호출을 재사용하고, 표시를 단계 컴포넌트로 나눈다(예: `StepHeader`, `EvidenceStep`, `GenerateStep`, `ReviewStep`, `ConfirmStep`). 세 종류가 공유.
- 목록 ↔ 학생 화면 전환과 현재 단계는 화면 상태(새로고침 시 목록으로 가도 됨).
- 색·글꼴은 지금 `src/styles.css` 토큰. 구분 단추 모양: 옅은 바탕 트랙 안의 흰 선택칸(시안).

## 테스트 기준

- 단위(가능한 순수 함수로): 약한 근거 이유 계산, 다음 미확정 학생 찾기, 단계 결정(초안 없음→1, 초안 있음 미확정→3의 첫 미확인 문장, 확정→4), 확정 단추 문구.
- 스모크(가짜 invoke): 목록 → 학생 → 1~4단계 흐름, 문장 빼기·되돌리기, 근거 붙이기, 키보드, 통합본·행발, 64px.
- **E2E(`e2e/eval.test.mjs`)를 새 흐름으로 고친다**: 교과마다 학생 열기 → 초안 만들기 → 문장마다 「맞아요, 확인했어요」 → 확정 → 통합본 → 복사·내보내기 → 진단 파일. 기존 단언(순서, 복사 글, 내보내기 형식)은 유지.
- 확인 명령 4개, `npm test`.
