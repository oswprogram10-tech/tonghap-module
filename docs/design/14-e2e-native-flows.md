# 설계 14: E2E 확장 — 대화상자·마이크가 필요한 흐름

설계 12의 화면 E2E는 네이티브 대화상자(파일 열기·저장)와 마이크가 필요한 흐름을 뺐다. 그중 데이터 손실·실제 환경 차이 위험이 큰 흐름을 실제 윈도우·WebView2에서 확인한다. **릴리스 빌드 동작은 바꾸지 않는다.**

## 테스트 연결 장치 (디버그 빌드 전용)

1. **대화상자 대체**: 프런트엔드의 대화상자 호출을 한 곳(`src/lib/dialogs.ts`의 `pickFiles`, `pickFile`, `pickFolder`, `saveFile`)으로 모은다(지금은 화면마다 `@tauri-apps/plugin-dialog`를 직접 부름 — 모두 이 래퍼로 바꾼다). 래퍼는 먼저 Rust 명령 `e2e_dialog_next(kind)`를 부른다:
   - 디버그 빌드이고 환경 변수 `TONGHAP_E2E_DIALOG_DIR`이 있으면, 그 폴더의 `queue.json`(테스트가 쓰는 파일: `[{ "kind": "open"|"save"|"folder", "paths": [...] }]`)에서 맨 앞 항목을 꺼내 돌려준다(종류가 다르면 오류).
   - 아니면 `null` → 래퍼가 원래 대화상자를 연다.
   - 릴리스 빌드에서는 명령이 항상 `null`.
2. **가짜 마이크**: E2E에서 앱을 띄울 때 WebView2 인자에 `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream`(필요하면 `--use-file-for-fake-audio-capture=<wav>`로 jfk.wav)을 더한다. 설계 12에서 만든 디버그 전용 인자 전달(`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` → 코드)로 넘긴다.

## 엔진과 모델

`e2e.yml`에 엔진 내려받기(`npm run fetch:engines`)와 whisper tiny 모델(설계 12와 같은 파일·해시, 캐시 공유)을 추가하고, 테스트 데이터 폴더의 `models/`에 앱이 기대하는 파일 이름으로 넣는다. 자막 모델 설정(`sttModelId`)을 tiny로 바꾸는 방법이 없으면 테스트 전용으로 디버그 빌드에서 `TONGHAP_E2E_STT_MODEL` 파일 경로를 쓰게 한다(릴리스 무관). 언어 모델은 이번에 다루지 않는다.

## 시나리오 (`e2e/native.test.mjs`, 기존 시나리오 뒤에 같은 세션으로 또는 별도 세션)

1. **사진 첨부**: 테스트가 만든 작은 PNG를 대화상자 대체로 고름 → 관찰 저장 → 기록 카드의 `<img>`가 asset 주소로 **실제로 그려짐**(`naturalWidth > 0`).
2. **음성 메모 → 자막**: 「음성 메모」 녹음 3초(가짜 마이크) → 저장 → 자막 상태가 대기 → 진행 → 완료 또는 「말소리를 찾지 못했습니다」(가짜 소리라 둘 다 통과) 중 하나로 **끝남**(5분 안). 실패 상태면 오류 문구를 출력하고 실패.
3. **백업 → 기록 추가 → 복원**: 암호로 백업 파일 저장(대화상자 대체) → 관찰 하나 더 저장 → 복원(파일 선택 대체, 확인 창 수락) → 추가한 관찰이 사라지고 원래 개수로 돌아옴, 사진·음성 첨부가 다시 표시됨, `before-restore-*` 폴더가 생김. **앱이 DB를 열고 있는 상태에서 윈도우가 파일을 옮기는 경로**를 확인하는 것이 핵심.
4. **학부모 리포트 PNG**: 포트폴리오 → 학생 → 학부모 리포트 → 이미지로 내보내기(저장 대체) → 파일이 있고 PNG 시그니처, 크기 1240x1754(헤더 읽기).
5. **메이킹북 인쇄**: 메이킹북 카드 「틀 인쇄」 → 미리보기가 열림 → `window.print`를 페이지에서 가짜로 바꿔 호출되는지만 확인(인쇄 대화상자는 띄우지 않음).

## 테스트 기준

- Rust: `e2e_dialog_next` — 환경 변수 없음·릴리스이면 `null`, 큐에서 순서대로 꺼냄, 종류가 다르면 오류, 큐가 비면 `null`(순수 함수로 테스트).
- 프런트엔드: 모든 대화상자 호출이 래퍼를 지나는지(`@tauri-apps/plugin-dialog` 직접 import가 `src/lib/dialogs.ts` 밖에 없음 — Node 테스트로 소스 검사).
- E2E 워크플로가 수동 실행으로 통과.
