# 설계 13: 메이킹북 인쇄 틀

활동 카드 중 메이킹북(주제책마다 1장, 16장)은 "접이 책 틀" 같은 종이 틀이 필요하다. 앱에서 그 틀을 바로 인쇄하게 한다. 틀은 카드 데이터의 짧은 안내 문구로 채운 **공통 양식 3가지**다. 학생 정보는 인쇄하지 않는다(이름 칸은 빈칸).

## 데이터

`data/activities/activities.json`의 메이킹북 카드에 `makingbook` 필드(스키마에 정의, 검증 포함):

```json
"makingbook": {
  "template": "zine8",
  "title": "우리 학교",
  "pages": ["학교 정문을 그려요", "우리 교실을 그려요", "좋아하는 곳을 그려요", "도서관을 그려요", "운동장을 그려요", "학교에서 하고 싶은 일"]
}
```

| 틀 | 종이 | 칸 | `pages` 수 |
|---|---|---|---|
| `zine8` | **A4 가로** 1장(2줄 x 4칸, 한 쪽 74.25 x 105mm)을 접고 가운데를 잘라 만드는 8쪽 책 | 표지(제목·「이름: ____」) + 속 6쪽 + 뒷표지(「다 만들었어요!」와 날짜 칸) | 6 |
| `card2` | A4 가로를 반으로 접는 카드 | 앞면(제목 + 그림 칸 + 안내 1) / 안쪽(안내 2 + 쓰기 줄) | 2 |
| `accordion4` | A4 가로 4칸 병풍 | 칸마다 안내 + 그림 칸, 첫 칸 위에 제목·이름 | 4 |

## 인쇄 화면

- 활동 카드 보기(카드 고르기 목록, 단원 화면의 카드에서 만든 차시 편집 창, 활동 카드 관리)의 메이킹북 카드에 「틀 인쇄」 버튼.
- 누르면 미리보기 창(전체 화면 모달): 실제 A4 비율의 틀 + 「인쇄」·「닫기」. 「인쇄」는 `window.print()`; `@media print`에서 틀만 보이고 나머지는 숨긴다(`@page { size: A4 landscape; margin: 0 }` — 세 틀 모두 가로, 틀은 mm 단위로 그린다).
- `zine8`은 접는 방법이 인쇄물에 들어가야 아이·교사가 접을 수 있으므로 위쪽 4칸을 180° 돌려 배치하고(접이 책 표준 배치), 접는 선(점선)과 자르는 선(가위 표시 + 실선, 가운데 가로선 중 가운데 두 칸 사이)을 표시한다. 미리보기 아래에 접는 순서 그림 4단계(인쇄되지 않음)를 둔다.
- 글자: 맑은 고딕, 안내 문구 14pt 이상, 제목 24pt 이상. 흑백 인쇄 기준(선은 진한 회색, 색 채움 없음).
- 교사 카드도 `makingbook`을 넣을 수 있게 활동 카드 관리 양식에 틀 선택(3가지)과 안내 칸(틀에 맞는 개수)을 추가.

## 구현 메모

- 틀 그리기는 순수 함수 `src/print/layouts.ts`(입력: 카드의 `makingbook` → 출력: 칸 목록 `{x, y, w, h, rotate, kind: 'cover'|'page'|'back', text}` mm 단위)로 만들고 React 컴포넌트가 그것을 SVG로 그린다. Node 테스트로 칸 좌표·회전·개수를 검사한다(`random.ts`처럼 import 없는 모듈).
- Rust의 활동 카드 구조체·검증(`src-tauri/src/db/activities.rs`)에 `makingbook`(선택) 추가: 메이킹북 카드에만, 틀별 안내 개수, 길이 제한. 기본 카드 전체가 Rust 검증을 통과하는 기존 테스트가 이 필드도 지킨다.

## 테스트 기준

- Node: `layouts.ts` — 세 틀의 칸 수(zine8 8칸, card2 2면, accordion4 4칸), zine8 윗줄 4칸이 180° 회전, 칸이 A4 안에 들어가고 서로 겹치지 않음.
- Rust: 교사 카드 `makingbook` 저장·검증(틀별 개수, 메이킹북이 아닌 카드에 있으면 거부).
- 스모크: 메이킹북 카드에서 「틀 인쇄」 → 미리보기 → `window.print` 호출(가짜로 바꿔 확인), 인쇄용 CSS에서 모달 밖이 숨겨지는지(`page.emulateMedia({ media: 'print' })` 스크린숏).
