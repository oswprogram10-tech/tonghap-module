# 설계 23: 칠판 타이머 안내 음성

`docs/PLAN.md`의 「안내 음성: 개발할 때 미리 음성 파일로 만들어 앱에 포함」. 사용자 결정: **MeloTTS(MIT)로 기본 음성을 만들어 넣고, 선생님이 문구별로 직접 녹음해 바꿀 수 있게**. 범위는 **타이머**만.

## 1. 문구 (`data/voice/cues.json` — 스키마와 검증 포함)

| id | 문구 | 언제 |
|---|---|---|
| `timer-1min` | 1분 남았어요. | 남은 시간이 1분이 될 때(전체 시간이 2분 이상일 때만) |
| `timer-30s` | 30초 남았어요. | 남은 시간이 30초(전체 1분 이상일 때만) |
| `timer-end` | 시간이 다 되었어요. 하던 것을 멈추고 선생님을 봐요. | 끝났을 때 |

- 숫자는 한글로 읽히게 생성 입력에서 「일 분」「삼십 초」로 넣고(화면 표시는 위 문구), 이 대응도 JSON에 둔다.

## 2. 기본 음성 만들기 (개발할 때 한 번, 앱에는 결과 파일만)

- `scripts/tts/generate.py`: MeloTTS(`melo.api.TTS(language='KR')`, 화자 `KR`, 속도 0.9)로 각 문구를 WAV로 만들고, 16kHz 모노로 줄여 Opus(`.ogg`, 24kbps)로 저장(`src/board/voice/<id>.ogg`) — 앱 크기를 작게. 변환은 ffmpeg가 있으면 쓰고, 없으면 WAV 그대로(크기 보고).
- 파이썬 의존성은 `scripts/tts/requirements.txt`에 버전 고정, 가상환경에서 실행. 앱 빌드·CI에는 들어가지 않는다(생성 결과만 커밋).
- `scripts/tts/README.md`: 다시 만드는 방법, 사용 모델(`myshell-ai/MeloTTS-Korean`, MIT)과 내부에서 쓰는 한국어 BERT·G2P의 라이선스 확인 결과(확인한 그대로 적고, 상업 이용이 막힌 것이 있으면 멈추고 보고).
- 고지: 정보 화면 오픈소스 목록/`THIRD_PARTY_NOTICES.md`에 「안내 음성: MeloTTS(MIT)로 생성」.

## 3. 재생 (`src/board/`)

- 타이머 탭에 소리 방식 선택: 「안내 음성」(기본) / 「삑 소리」 / 「끔」. 지금 `sound.ts`의 켬/끔 저장(localStorage)을 세 가지로 늘린다(예전 'off'는 「끔」으로).
- 정해진 시점에 해당 문구를 재생(`HTMLAudioElement`). 선생님 녹음이 있으면 그것을, 없으면 기본 파일. 재생 실패 시 삑 소리로 대신.
- 일시정지·다시 시작·시간 바꾸기에서 같은 문구가 두 번 나오지 않게(이미 지난 시점은 건너뜀). 순수 함수로 「이번 틱에 낼 문구」를 계산해 테스트.

## 4. 선생님 녹음으로 바꾸기

- 타이머 탭의 「안내 음성 바꾸기」(교사 PC 메인 창의 칠판 설정이 있으면 거기, 없으면 칠판 창 타이머 탭 안 작은 설정): 문구마다 「듣기」「녹음」「기본으로」.
- 녹음은 기존 음성 메모 녹음 부품을 재사용(마이크, 최대 10초). 저장: DB 설정 표 `voice.<id>`에 WAV(16kHz 모노) base64. 아이 데이터가 아니라 교사 목소리지만 DB에 두면 백업에 함께 들어가고 암호화된다.
- Rust 명령: `voice_get(id) -> Option<Vec<u8>>`, `voice_set(id, wav)`(형식·길이 검사: `stt::validate_wav` 재사용, 10초·1MB 이하), `voice_clear(id)`. id는 cues.json에 있는 것만.
- 칠판 창은 `voice_get`으로 받아 Blob URL로 재생.

## 테스트 기준

- 검증 스크립트: cues.json 스키마, 모든 id의 기본 파일 존재, 파일 크기 합계 보고.
- 순수 함수: 타이머 시점 계산(전체 시간별, 일시정지·재개·시간 변경, 중복 없음).
- Rust: voice_set 형식·길이·id 거부, 왕복, 기본으로.
- 스모크: 소리 방식 세 가지 전환, 녹음 저장 후 그 녹음이 재생 대상, 「기본으로」.
- 실제 소리 품질은 사용자가 듣고 판단(생성한 파일을 스크래치패드에 모아 보고).
